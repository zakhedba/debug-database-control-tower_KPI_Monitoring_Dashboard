# Responsible publication and security review

This repository is intended for a **public, synthetic-data demonstration**. Do not run unfamiliar scripts against production. Prior to `git add`, inspect every file, embedded document property, comment and sample value; `gitignore` does not remove previously committed data. Avoid client data, live CSVs, RMAN logs, backups, private topology/hostnames, usernames, email addresses, keys and passwords. Review entire commit history before publication. Use principle of least privilege for SQL collectors and exports. RMAN and SQL agent logs may disclose environment information. Hosting the HTML dashboard is an independent security decision: local file mode is recommended until authentication, file permissions, HTML/CSV handling and exposure paths are reviewed. Separate proof-of-concept outcomes from production evidence.
